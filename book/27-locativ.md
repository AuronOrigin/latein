:::ziel Lernziele
Nach diesem Kapitel kannst du:
- den Locativ sicher anwenden,
- *in + Akkusativ* (wohin?) und *in + Ablativ* (wo?) unterscheiden,
- die Ortsadverbien (*hīc, ibi, ibidem, illīc, undīque*) einordnen,
- die Richtung eines Satzes eindeutig bestimmen.
:::

**inde** — von daher · **eō** — dorthin · **rēgīna, -ae** *f.* — Königin
:::

## Der Locativ: der versteckte Fall

Der Locativ existiert im Deutschen nicht — er steckt in **Präpositionalphrasen** versteckt. Er kommt nur vor bei:

| Wörter | Bedeutung | Beispiele |
|---|---|---|
| **Städte- und Ländernamen** | wo? | *Rōmae*, *Athēnīs*, *Germaniā* |
| **domī** | zu Hause | *domī sum* — „ich bin zu Hause" |
| **rēgī, rēgnī** | in der Sache, beim König | *rēgī iūstitia* |
| **bellī, vēlī** | im Krieg, in der Sache | *bellī fortitūdō* |
| **militiae** | beim Militärdienst | |
| **rūrī** | auf dem Land | |
| **hūc, hūc** | hierher | *hūc venit* |

:::begriff Locativ
**Begriff:** Ein **seltener Kasus** (nur Singular, nur in bestimmten Wörtern), der im Deutschen durch eine Präposition wiedergegeben wird: *Rōmae* = „in Rom".
**Herkunft:** lat. *locāre* = „setzen, platzieren“; *locus* = „Ort“.
**Entscheidungshilfe:** Der Locativ steht bei Städten **ohne** Präposition, der Ablativ der Herkunft (Rōmā = von Rom) **ebenfalls ohne** Präposition. Der Unterschied liegt in der Bedeutung: *Rōmae* = „in Rom" (mit *in* gedacht), *Rōmā* = „von Rom" (weg von dort).
**Verwandte Begriffe:** *Kasus*, *Ablativ*, *Genitiv*, *Locativus*.
:::

## *in* mit Akkusativ und Ablativ

Das Wort *in* trägt **zwei** Bedeutungen, und die unterscheiden sich am Kasus:

| Konstruktion | Frage | Beispiel | Übersetzung |
|---|---|---|---|
| ***in + Akkusativ*** | wohin? | *in hortum īvit* | Er ging **in den Garten** (hinein). |
| ***in + Ablativ*** | wo? | *in hortō erat* | Er war **im Garten** (drinnen). |

Und außerhalb von *in*:

| Frage | Form | Beispiel |
|---|---|---|
| wohin? | Akkusativ (ohne Präp.) | *Rōmam īvit* |
| wo? | Locativ / *in + Abl.* | *Rōmae erat* / *in hōrtō erat* |
| woher? | Ablativ (ohne Präp.) | *Rōmā vēnit* |

:::merksatz Die drei Richtungen
```
  Rōmam    →  WOHIN?    (Akkusativ)     "nach Rom"
  Rōmae    →  WO?       (Locativ)      "in Rom"
  Rōmā     →  WOHER?    (Ablativ)      "von Rom"
```
Diese Dreiergruppe ist ein Musterbeispiel dafür, wie **genau** das Latein ist: Drei Wörter, drei Bedeutungen, kein Nebensatz nötig.
:::

## Die Ortsadverbien

Viele Ortsadverbien sind historisch **Kasusformen** — man kann sie deshalb oft ersetzen:

| Adverb | Bedeutung | Ersetzbar durch |
|---|---|---|
| **hīc** | hier | *in hoc loco* (Abl.) / *hōc locō* |
| **ibi** | dort | *illīc* / *eō locō* |
| **ibidem** | ebendort | *in eō locō* |
| **illīc** | dort drüben | |
| **undīque** | überall | *in omnibus locīs* |
| **hāc** | auf diesem Weg (hierher) | *hāc vīā* — Akkusativ der Richtung |
| **eā** | auf dem Weg (dorthin) | *eā vīā* |
| **inde** | von daher | *ab eō locō* |
| **eō** | dorthin | |

:::begriff Adverbien als Kasusformen
**Begriff:** Viele lateinische Adverbien sind sprachgeschichtlich **Kasusformen** von Nomen — ihr Ort ist verraten.
**Beispiel:** *hīc* „hier" ← *hic, haec, hoc*; *ibi* „dort" ← *ibi*; *inde* „von daher" ← *inde* (Ablativ); *eō* „dorthin" ← *eō* (Akkusativ); *hāc* „hierher" ← *hāc* (Ablativ); *eā* „dorthin" ← *eā* (Ablativ).
**Wozu?** Weil man in vielen Sätzen Adverb und Präpositionalphrase gegeneinander austauschen kann, ohne die Bedeutung zu ändern: *hīc erat* = *in hōrtō erat*.
**Verwandte Begriffe:** *Adverb*, *Kasus*, *Ablativ*, *Locativ*.
:::

## Adverbien der Richtung: der versteckte Akkusativ

Wenn eine Richtung ohne Nomen angegeben wird, steht das Adverb im Akkusativ:

> *Vēnit hūc.* — „Er kam **hierher**."
> *Eō properābat.* — *eō* ist Akkusativ: „Er eilte **dorthin**."

:::warn Adverb oder Akkusativ?
*hīc* (hier) = Lokaladverb, *hūc* (hierher) = Akkusativ mit Richtung. Der Unterschied ist nur ein Buchstabe — und genau darin stecken die Fehler:
- **hīc, ibi, ibidem, illīc, undīque** = **wo?** (unveränderlich)
- **hūc, eō, hāc, eā, inde** = Richtung oder Herkunft (mit Präposition: *in hūc*, *ad eō*)
:::
