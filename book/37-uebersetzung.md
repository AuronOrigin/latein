## Warum Übersetzen das Kerngeschäft ist

Formenlehre kann man auswendig lernen. Übersetzen kann man **nur üben**. Deshalb ist dies das wichtigste Kapitel des Buches — wichtiger als alle Paradigmen zusammen.

Die gute Nachricht: Übersetzen ist ein **Handwerk** mit einem **Werkzeugkasten**, nicht eine Kunst des Auserkennens. Und das Werkzeug hat nur wenige Teile:

| Werkzeug | Wozu |
|---|---|
| **Der Fragebaum** | um die Rolle eines Wortes zu bestimmen |
| **Die sieben Schritte** | um die Reihenfolge der Übersetzung festzulegen |
| **Das Einrücken (gradatim)** | um den Satzbau zu „entfalten“ |
| **Das Wörterbuch** | um Formen und Bedeutungen zu finden |

## Der Fragebaum

Für jedes Wort im Satz stellst du in dieser Reihenfolge Fragen. Die erste Frage, die mit „ja“ beantwortet wird, verrät dir die Rolle:

```
                    ┌──────────────────────────┐
                    │  Welche Form?             │
                    │  Nom. / Gen. / Dat. /      │
                    │  Akk. / Abl. / Voc.        │
                    └────────────┬─────────────┘
                                 │
        ┌────────────────────────┼────────────────────────┐
        │                        │                        │
   Nomen/Adjektiv            Pronomen                   Adverb
        │                        │                        │
        ▼                        ▼                        ▼
┌───────────────┐      ┌────────────────┐        ┌──────────────┐
│ Verb?         │      │ Relativ? →     │        │ Adverbium    │
│ (Nomen/       │      │ Bezugswort     │        │ → adverbial  │
│  Infinitiv)   │      │ suchen         │        │              │
└───────┬───────┘      │ Subjekt?       │        └──────────────┘
        │              │ Objekt?         │
        ▼              │ Adverbial?     │
┌───────────────┐      └────────────────┘
│ Im Akkusativ? │
│ → Objekt des  │
│   Verbs       │
└───────┬───────┘
        │ nein
        ▼
┌───────────────┐
│ Im Genitiv?   │  → Abhängigkeit / Besitz
└───────┬───────┘
        │ nein
        ▼
┌───────────────────────┐
│ Nominativ + Verb      │ → SUBJEKT
└───────────────────────┘
```

:::begriff Fragebaum
**Begriff:** Eine **Entscheidungshilfe**, die in festen Fragen prüft, welche syntaktische Rolle ein Wort im Satz hat. Der Name stammt von der Form des Diagramms: von der Wurzel (der Form) verzweigt sich der Baum (die möglichen Funktionen).
**Wozu?** Er verhindert, dass man ratet. Man beginnt **oben** und geht **nach unten**, bis die erste „ja“-Antwort kommt.
**Wichtig:** Der Baum wird **nicht** für jedes Wort einzeln durchlaufen — sondern für die **schwierigen** Wörter. Bei einem einfachen Satz mit klarem Subjekt braucht man ihn nicht.
**Verwandte Begriffe:** *Satzanalyse*, *Indizierung*, *Rektion*.
:::

## Die sieben Schritte der Satzanalyse

Diese Reihenfolge ist erprobt. Wer sie einmal geübt hat, übersetzt flüssiger als mit jedem Wörterbuch allein.

### Schritt 1: Das Verb finden

> Suche zuerst das **Verb** (finite Form oder Infinitiv). Es ist das Gerüst des Satzes.

*Magister discipulōs admonuit.* → Verb: *admonuit*.

### Schritt 2: Das Subjekt finden

> Suche den **Nominativ**, der zum Verb passt (Person und Zahl).

→ *Magister* (3. Sg., passt zu *admonuit*).

### Schritt 3: Alle übrigen Nomen nach ihrer Rolle prüfen

> Für jedes Nomen: Ist es Objekt (Akkusativ), Genitiv, Dativ, Ablativ, Apposition?

→ *discipulōs* = Akkusativ Plural → Objekt.

### Schritt 4: Adverbien und Präpositionen zuordnen

> *admonuit* = „ermahnen“ → Dativ oder Akkusativ? Der Akkusativ *discipulōs* ist bereits Objekt. Also ist alles klar.

### Schritt 5: Den Satz **wortwörtlich** aufschreiben

> Noch **kein** idiomatisches Deutsch. Nur die Einzelbedeutungen in lateinischer Reihenfolge.

*Magister — discipulōs — admonuit* → „Lehrer — die Schüler — ermahnt“

### Schritt 6: Die deutsche Wortstellung herstellen

> Das Deutsche braucht Subjekt – Verb – Objekt. Das Lateinische nicht. Jetzt wird umgestellt.

→ „Der Lehrer ermahnt die Schüler."

### Schritt 7: Idiomatisieren und prüfen

> Passt der deutsche Satz? Fehlt etwas? Ist etwas überflüssig?

→ „Der Lehrer ermahnt die Schüler." ✓

:::merksatz Die sieben Schritte
**1. Verb → 2. Subjekt → 3. Nomen einordnen → 4. Adverbien → 5. wortwörtlich → 6. umstellen → 7. idiomatisieren.**
Schritt 5 ist der wichtigste: Wer direkt auf Schritt 7 springt, übersetzt „nach Gefühl“ und macht Fehler.
:::

## Gradatim: das Einrücken

Bei längeren Sätzen hilft eine Technik, die aus dem Rhetorikunterricht stammt: Man **rückt die Satzteile ein** und ordnet sie so, wie sie grammatisch zusammengehören. Am Ende rückt man alles in die deutsche Reihenfolge.

Beispiel:

> *Dux qui clārus fuit, exercitum in Galliam dūxit et hostēs fūgit.*

```
Dux                     qui clārus fuit
 ├─ Subjekt              ├─ Relativsatz (zu Dux)
 │
exercitum               in Galliam
 ├─ Objekt               ├─ Adverbiale (wohin?)
 │
dūxit                   et          hostēs fūgit
 ├─ Verb 1                              ├─ Verb 2
 └─ Subjekt des 2. Verbs: hostēs ───────┘
```

Und so geht es zurück ins Deutsche:

> „Der Feldherr, der berühmt war, führte das Heer nach Gallien und schlug die Feinde in die Flucht."

:::begriff Gradatim
**Begriff:** Eine **Übersetzungsmethode**, bei der der lateinische Satz in seine Bestandteile zerlegt und **eingerückt** wird, um die Abhängigkeiten sichtbar zu machen; erst danach wird linear übersetzt.
**Herkunft:** lat. *gradus* = „Schritt“; *gradatim* = „schrittweise“.
**Wozu?** Sie macht komplexe Sätze **beherrschbar** und zeigt, wo ein Nebensatz „hängt“.
**Verwandte Begriffe:** *Satzanalyse*, *Satzbauplan*, *Indizierung*.
:::

## Die goldene Regel der Wortstellung

Lateinisch:

> **Das wichtigste Wort steht am **Ende**.**

Das gilt für:

- **Subjekt und Verb** stehen **nicht** am Anfang (Ausnahme: das Betonungsgesetz). Das Verb steht meist spät.
- **Adverbien** stehen gern **vor** dem Verb.
- **Objekte** stehen gern **vor** dem Verb (*discipulōs admonuit*), das Pronomen *eum/me* steht **nach** dem Verb (*admonuit eum*).
- **Präposition + Akkusativ** steht gern ganz am Ende.

| Lateinische Reihenfolge | Deutsches Ergebnis |
|---|---|
| *Magister discipulōs admonuit.* | Der Lehrer ermahnt die Schüler. |
| *Discipulōs magister admonuit.* | Die Schüler ermahnt der Lehrer. (gleiche Bedeutung!) |
| *Admonuit magister discipulōs.* | Ermahnte der Lehrer die Schüler. |

:::warn Die Fehldeutung
Weil das Verb spät steht, übersetzen Anfänger oft: „Lehrer die Schüler ermahnt“ — das ist **kein** deutscher Satz. Das Verb muss im Deutschen an die Stelle, die deutsche Syntax verlangt: an Position 2 bei Nebensatz oder Aussagesatz.
**Regel:** Immer erst **wortwörtlich**, dann **umstellen**, dann **idiomatisieren**.
:::

7. *Quī multa vidēt, multa discit.*
