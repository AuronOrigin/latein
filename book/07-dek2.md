## Die zweite Gruppe

Nach den Nomen auf **-a** kommen die auf **-us, -um, -er, -ium**. Alle haben die Endung **-ī** im Genitiv Singular — das ist ihr Erkennungsmerkmal.

| | *servus* (m.) | *verbum* (n.) | *puer* (m.) |
|---|---|---|---|
| **Nominativ** | serv**us** | verb**um** | pu**er** |
| **Genitiv** | serv**ī** | verb**ī** | puer**ī** |
| **Dativ** | serv**ō** | verb**ō** | puer**ō** |
| **Akkusativ** | serv**um** | verb**um** | puer**um** |
| **Ablativ** | serv**ō** | verb**ō** | puer**ō** |
| **Vokativ** | serv**us** | verb**um** | pu**er** |
| **Nominativ Pl.** | serv**ī** | verb**a** | puer**ī** |
| **Genitiv Pl.** | serv**ōrum** | verb**ōrum** | puer**ōrum** |
| **Dativ Pl.** | serv**īs** | verb**īs** | puer**īs** |
| **Akkusativ Pl.** | serv**ōs** | verb**a** | puer**ōs** |
| **Ablativ Pl.** | serv**īs** | verb**īs** | puer**īs** |

## Drei Besonderheiten

### 1. Das Neutrum plural auf -a

Das ist die eigenartigste Form der lateinischen Grammatik: **Das Neutrum im Plural bildet die Endungen wie ein Nomen der 1. Deklination.**

| | *verbum* | → | *verba* |
|---|---|---|---|
| Nominativ Plural | verb**a** | | „die Wörter" |
| Akkusativ Plural | verb**a** | | |
| Vokativ Plural | verb**a** | | |

Warum? Weil im Latein ein **Neutrum Plural** häufig eine **Menge** oder eine **Gesamtheit** bezeichnet, und Mengen werden im Latein wie Nomen der 1. Deklination behandelt.

:::merksatz Warum heißen die „Kriege" *bella*?
Weil *bellum* (Krieg, n.) im Plural *bella* heißt — und *bella* **eigentlich** die 1. Deklination ist! Das Neutrum Plural der 2. Deklination hat die Endungen der 1. Deklination angenommen. Daher der bekannte Witz: * Bella, bella, nulla bella! * — „Kriege, Kriege, keine Kriege!"
:::

### 2. Der Vokativ auf -e

Bei Nomen auf **-um** (Neutrum) lautet der Vokativ wie der Nominativ: *templum!* Bei Nomen auf **-us** und **-er** ebenfalls: *servus!* *puer!* Der Vokativ auf **-e** (*amīce!* „o Freund!") kommt nur bei Nomen der **3. Deklination** vor (dort, wo der Stamm auf einen Konsonanten endet).

### 3. Unregelmäßige Pluralformen

| Singular | Plural | Anmerkung |
|---|---|---|
| *fīlius* (Sohn) | **fīliī** | *fīliōrum*, *fīliīs* — regelmäßig gebildet, aber der Nominativ Plural ist *fīliī* statt des erwarteten *fīlius* |
| *deus* (Gott) | **dī** (auch *deī*) | *deōrum*, *dēīs* |
| *manus* (Hand, 4. Dekl.) | **manūs** | regelmäßig |
| *nox* (Nacht, 3. Dekl.) | **noctēs** | unregelmäßig (3. Dekl.) |

:::begriff Vokativ
**Begriff:** Der **Anruffall** — die Form, die man benutzt, um jemanden direkt anzusprechen: *Amīce!* „O Freund!"
**Herkunft:** lat. *vocāre* = „rufen, rufen lassen“.
**Beispiel:** *O Rōma!* / *Salve, magister!*
**Wozu?** In der Alltagssprache fast überflüssig (der Anrede folgt schon der Nominativ), in der Dichtung und in der Anrede aber häufig — *puella, dic mihi …!*
**Verwandte Begriffe:** *Nominativ*, *Kasus*, *Anrede*.
:::

## Das Genus der 2. Deklination

| Endung | Genus | Beispiele | Regel |
|---|---|---|---|
| **-us** | maskulin | *servus, amicus, equus* | Regel: fast immer maskulin |
| **-er** | maskulin | *puer, magister, liber* | Regel: fast immer maskulin |
| **-um** | **neutrum** | *verbum, bellum, donum* | Regel: immer neutrum |
| **-ium** | **neutrum** | *atrium, oppidum?* (nein, 2. Dekl.) → *imperium, studium* | immer neutrum |

Ausnahmen bei **-us**: Die 4. Deklination hat einige feminin: *domus* (Haus), *mānus* (Hand), *pēs?* (nein, 3. Dekl.), *cāsus* (Fall). Und *Asicus?* irrelevant.

:::warn Die eine große Falle: *domus*
*domus, -ūs* ist **feminin** und wird **4. Deklination** dekliniert (im Genitiv *domūs*). Der Nominativ sieht aus wie 2. Deklination, ist es aber nicht.
Ähnlich: *mānus, -ūs* (die Hand), *pēs, pedis* (der Fuß) — die beiden „Ausnahmen mit -us", die man kennen muss.
:::

## Zwei Deklinationen im Vergleich

| | 1. Deklination | 2. Deklination |
|---|---|---|
| Stamm | **-ā-** | **-i-**, **-u-**, **-e-** |
| Genitiv Sg. | -ae | **-ī** |
| Akkusativ Sg. | -am | **-um** |
| Ablativ Sg. | -ā | **-ō** |
| Nom. Pl. | -ae | -ī (m.) / **-a** (n.) |
| Gen. Pl. | -ārum | -ōrum |
| Dat./Abl. Pl. | -īs | -īs |
| Typisch | *puella, aqua* | *servus, verbum* |

## Übungen

:::uebung
**A. Formen bilden.** Bilde von *amicus* alle Formen, von *verbum* die sechs Singularformen.

**B. Genus bestimmen.** *donum, equus, magister, imperium, puer, templum, liber.*

**C. Übersetzen.**
1. *Servi dominō in hōrtō rosās portant.*
2. *Puer equum in agrō amat?* → *Equum* ist Akkusativ: *Der Junge liebt das Pferd.*
3. *Magister discipulōs verba docet.*
4. *Bella in Galliā multō sunt?* → korrigieren!

**D. Neutrum Plural.** Bilde den Plural (alle Formen) von *bellum* und *verbum*, und erkläre, warum *bella* eine 1.-Deklinationsform ist.
:::

:::loesung
**A.**
*amicus* (Nom.), *amicī* (Gen.), *amicō* (Dat.), *amicum* (Akk.), *amicō* (Abl.), *amicī* (Nom. Pl.), *amicōrum* (Gen. Pl.), *amicīs* (Dat./Abl. Pl.), *amicōs* (Akk. Pl.);
*verbum, verbī, verbō, verbum, verbō, verba, verbōrum, verbīs, verba, verbīs*.

**B.**
*donum* n. · *equus* m. · *magister* m. · *imperium* n. · *puer* m. · *templum* n. · *liber* m.

**C.**
1. „Die Sklaven bringen dem Herrn im Garten Rosen."
2. „Der Junge liebt das Pferd."
3. „Der Lehrer lehrt die Schüler die Wörter." (*verba* Akkusativ Plural — das direkte Objekt von *docēre*.)
4. Korrekt: *Bella in Galliā multa sunt.* — *multa* (Neutrum Plural von *multus*) statt *multō*; *sunt* (nicht *est*).

**D.**
*bellum* → *bella, bellōrum, bellīs, bella, bellīs* · *verbum* → *verba, verbōrum, verbīs, verba, verbīs*.
Das Neutrum Plural hat die Endungen der 1. Deklination übernommen — historisch vermutlich, weil im Latein Neutra im Plural oft **Mengen** bezeichnen und Mengen wie feminine a-Nomen behandelt wurden.
:::
