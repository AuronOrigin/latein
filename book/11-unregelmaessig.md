:::ziel Lernziele
Nach diesem Kapitel kannst du:
- die sechs wichtigsten unregelmäßigen Verben vollständig konjugieren,
- *esse* als Kopula, Hilfsverb und Infinitiv gebrauchen,
- das Futur und Imperfekt dieser Verben bilden,
- die Hilfsverben *posse*, *licet*, *oportet*, *opus est* verstehen.
:::

:::wortschatz
**sum, esse, fuī, futūrus** — sein · **possum, posse, potuī** — können, vermögen ·
**ferō, ferre, tulī, lātum** — tragen, bringen · **fīō, fierī, factus sum** — werden, geschehen ·
**eō, īre, iī (īvī), itum** — gehen · **dō, dare, dedī, datum** — geben ·
**volō, velle** — wollen · **nōlō, nōlle** — nicht wollen · **mālō, mālle** — lieber wollen ·
**licet** — es ist erlaubt · **oportet** — es ist nötig · **opus est** — es ist nötig
:::

## Warum diese sechs?

In jedem lateinischen Text — von Cäsar bis Cicero, von der Inschrift bis zur Bibelübersetzung — tauchen diese Verben auf. Sie sind das **Gerüst**, an dem sich der Rest der Sprache aufhängt.

| Verb | Übersetzung | Hauptform | Besonderheit |
|---|---|---|---|
| **sum, esse** | sein | *sum, esse, fuī, futūrus* | Wurzel **es-**; unregelmäßig in fast allen Formen |
| **possum, posse** | können | *possum, posse, potuī* | = *pot-**sum***; wird wie *sum* konjugiert |
| **ferō, ferre** | tragen, bringen | *ferō, ferre, tulī, lātum* | Perfekt **tulī** (vom Perfektstamm *tul-*); Unregelmäßigkeiten überall |
| **fīō, fierī** | werden, geschehen | *fīō, fierī, factus sum* | **Passiv** ohne *-r*, aber **aktive** Bedeutung |
| **eō, īre** | gehen | *eō, īre, iī, itum* | wie *ferō* gebaut: *eō, īs, it, īmus, ītis, eunt* |
| **dō, dare** | geben | *dō, dare, dedī, datum* | wie *ferō*: *dō, dās, dat, damus, datis, dant* |

## *sum, esse*: das Herzstück

### Präsens aktiv

| | Sg. | Pl. |
|---|---|---|
| 1. | **sum** | **sumus** |
| 2. | **es** | **estis** |
| 3. | **est** | **sunt** |

### Die übrigen Tempora

| | Präsens | Imperfekt | Perfekt | Futur I |
|---|---|---|---|---|
| 1. Sg. | sum | eram | fuī | erō |
| 2. Sg. | es | erās | fuistī | eris |
| 3. Sg. | est | erat | fuit | erit |
| 1. Pl. | sumus | erāmus | fuimus | erimus |
| 2. Pl. | estis | erātis | fuistis | eritis |
| 3. Pl. | sunt | erant | fuērunt | erunt |

### *esse* als Hilfsverb

*esse* ist zugleich Kopula, Hilfsverb des Passiv und Infinitiv:

| Funktion | Beispiel | Übersetzung |
|---|---|---|
| **Kopula** | *Cicero consul est.* | Cicero ist Konsul. |
| **Hilfsverb (Passiv)** | *hostēs victī sunt.* | Die Feinde wurden besiegt. |
| **Infinitiv** | *putō eum esse sapientem.* | Ich glaube, dass er weise ist. |
| **Partizip** | *futūrus sum* | ich werde (sein) — Futurpartizip |

:::begriff Kopula und Hilfsverb
**Begriff:** *esse* ist zugleich **Kopula** (verbindet Subjekt und Prädikat) und **Hilfsverb** (bildet Passiv, Futur und periphrastische Ausdrücke).
**Wichtig:** *esse* bildet das Passiv **zusammen mit** dem Partizip Perfekt: *amātum est* = „ist geliebt worden" = „ist geliebt".
**Verwandte Begriffe:** *Kopula*, *Passiv*, *Infinitiv*, *Partizip Perfekt*, *Futurpartizip*.
:::

## *possum, posse*: „können"

*possum* ist etymologisch *pot- + sum* und wird deshalb **wie *sum*** konjugiert — mit einer Ausnahme: der StummbPartner *s* fällt weg, wenn der Vokal davor betont ist.

| | 1. Sg. | 2. Sg. | 3. Sg. | 1. Pl. | 2. Pl. | 3. Pl. |
|---|---|---|---|---|---|---|
| Präsens | **possum** | **potes** | **potest** | **possumus** | **potestis** | **possunt** |
| Imperfekt | poteram | poterās | poterat | poterāmus | poterātis | poterant |
| Perfekt | potuī | potuistī | potuit | potuimus | potuistis | potuērunt |

## *ferō, ferre*: tragen, bringen

Ein wirkliches Unregelmäßigkeits-Verb:

| | 1. Sg. | 2. Sg. | 3. Sg. | 1. Pl. | 2. Pl. | 3. Pl. |
|---|---|---|---|---|---|---|
| Präsens | **ferō** | **fers** | **fert** | **ferimus** | **fertis** | **ferunt** |
| Infinitiv | ferre | | | | | |
| Perfekt | **tulī** | tulistī | tulit | tulimus | tulistis | tulērunt |
| Partizip | **lātum** | | | | | |

:::merksatz Die Unregelmäßigkeiten von *ferō*
Präsens: *ferō, fers, fert, ferimus, fertis, ferunt* — das *r* fällt in der 2. und 3. Person Sg. aus (wie *ferrō* → *fertis*).
Perfekt: **tulī** — der Perfektstamm *tul-* ist völlig anders (*ferre* → *tulī*, wie *ferō → tulī*).
Partizip: **lātum** — wieder ein anderer Stamm.
Perfektpassiv: **lātus est**.
:::

## *fīō, fierī*: werden

:::warn Das Passiv mit aktiver Bedeutung
*fīō* hat eine **passive Form** (*fītur*, „er wird“) und eine **aktive Bedeutung** („er wird, es geschieht“). Vergleichbar mit dem Deutschen: *Er wird krank* — Form: Passiv, Bedeutung: aktiv.
*fieri* (mit *e*!) ist der Infinitiv, *fīō* (mit *ī*) die 1. Person. Der Perfekt ist eine **Periphrase**: *factus sum* = „ich bin geworden".
:::

| | 1. Sg. | 2. Sg. | 3. Sg. | 1. Pl. | 2. Pl. | 3. Pl. |
|---|---|---|---|---|---|---|
| Präsens | **fīō** | **fīs** | **fit** | **fīmus** | **fītis** | **fiunt** |
| Infinitiv | fierī | | | | | |
| Perfekt | factus sum | factus es | factus est | factī sumus | factī estis | factī sunt |

## *eō, īre*: gehen

| | 1. Sg. | 2. Sg. | 3. Sg. | 1. Pl. | 2. Pl. | 3. Pl. |
|---|---|---|---|---|---|---|
| Präsens | **eō** | **īs** | **it** | **īmus** | **ītis** | **eunt** |
| Infinitiv | īre | | | | | |
| Perfekt | iī (īvī) | iistī (īvistī) | iit (īvit) | iimus (īvimus) | iistis (īvistis) | iērunt (īvērunt) |

:::warn Zwei Formen für das Perfekt
*īre* hat im Perfekt **zwei** Formen: die klassische *iī, iistī, iit, iimus, iistis, iērunt* und die jüngere, häufigere *īvī, īvistī, īvit, īvimus, īvistis, īvērunt*. Für den Anfang genügt *īvī*.
:::

## Die Merkwörter: die häufigsten unregelmäßigen Einzelwörter

Diese Wörter tauchen in fast jedem lateinischen Text auf und sind **keine** Konjugationen, sondern Einzelfälle:

| Wort | Übersetzung | Anmerkung |
|---|---|---|
| **volō, velle, voluī** | ich will | 1. Pers. Sg. *volō*, Infinitiv mit Doppel-l |
| **nōlō, nōlle** | ich will nicht | wie *volō* |
| **mālō, mālle** | ich will lieber | wie *volō* |
| **licet** | es ist erlaubt | + Infinitiv; 3. Pers. Sg. (z. B. *licet mihi ire*) |
| **oportet** | es ist nötig | + Infinitiv |
| **opus est** | es ist nötig | + Ablativ: *opus est sapientiā* |
| **coepī, coepisse** | ich habe begonnen | Perfektform, wird wie ein Präsens gebraucht |
| **memini** | ich erinnere mich | 3. Deklination; *meminisse* = Perfekt |
| **putō, putāre** | ich denke, glaube | regelmäßig, aber 3. Pers. Sg. *putat* |
| **dō, dare** | ich gebe | *dō, dās, dat, damus, datis, dant* |
| **faciō, facere** | ich mache | *faciō* statt *facō* |

:::merksatz Die drei Hilfsverben, die man im Schlaf kennen muss
**libet** (es gefällt mir) · **licet** (es ist erlaubt) · **oportet** (es ist nötig) —
alle drei nehmen einen **Infinitiv**: *mihi licet ire* = „mir ist es erlaubt zu gehen".
:::

## Übungen

:::uebung
**A. Konjugieren.** Bilde die Präsensformen (Indikativ Aktiv):
1. *sum* 2. *possum* 3. *ferō* 4. *fīō* 5. *eō* 6. *dō*

**B. Formen bestimmen.** Nenne Tempus, Person und Numerus:
7. *fuī* 8. *possuī?* 9. *fertis* 10. *fīunt* 11. *it* 12. *factus est*

**C. Übersetzen.**
13. *Rōmānī fortēs sunt et hostēs vincere possunt.*
14. *Pueri ad schōlam ībunt.*
15. *Mihi licet dicere.*

**D. Verstehen.** Erkläre die Form: *futūrus sum* — wozu dient sie?
:::
