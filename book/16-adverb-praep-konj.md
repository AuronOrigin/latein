## Adverbien: die unveränderlichen Zeit- und Artwörter

Adverbien sind **unveränderlich** und beantworten vier Fragen:

| Frage | lateinisch | Beispiel |
|---|---|---|
| **Wann?** | wann? | *tunc, nunc, hodiē, semper, numquam, mox, statim* |
| **Wo?** | wo? | *hic, ibi, ibidem, ubi, unde, omnis* |
| **Wie?** | wie? | *bene, male, celeriter, pulchrē, fortiter* |
| **Wie viel / wie sehr?** | quantum | *multum, parum, valde, satis, nimis* |

:::begriff Adverb
**Begriff:** Ein **unveränderliches** Wort, das ein Verb näher bestimmt (Art, Weise, Zeit, Ort, Grad) — im Deutschen adverbial gebrauchter Infinitiv oder Grundwort.
**Herkunft:** lat. *adverbum* = „das Wort **daneben**“ (*ad-*(zu) + *verbum*); es steht beim Verb.
**Wichtig:** Adverbien werden **nicht** dekliniert und stehen in der Regel **nah am Verb**.
**Verwandte Begriffe:** *Adjektiv*, *Konjugation*, *Komparation*.
:::

### Adverbien aus Adjektiven

Viele Adverbien sind aus Adjektiven abgeleitet — die Form verrät es:

| Adjektiv | Adverb | Übersetzung |
|---|---|---|
| *bonus, bona, bonum* | **bene** | gut |
| *malus, mala, malum* | **male** | schlecht |
| *pulcher, pulchra, pulchrum* | **pulchrē** | schön |
| *fortis, forte* | **fortiter** | tapfer |
| *celer, celere* | **celeriter** | schnell |
| *facilis, facile* | **faciliter** | leicht |

Die Regel: **Neutrum des Adjektivs + -ē** (*pulchrē*), oder die Form auf **-iter** (*fortiter*).

### Steigerung der Adverbien

| Positiv | Komparativ | Superlativ |
|---|---|---|
| bene | **melius** | **optimē** |
| male | **peius** | **pessimē** |
| multum | **plūs** | **plūrimum** |
| magnopere | **magis** | **maximē** |
| bene | **melius** | **optimē** |
| (regelmäßig) *celeriter* | *celerius* | *celerrimē* |

:::warn Achtung beim Superlativ
Der **Superlativ des Adverbs** bildet sich wie der des Adjektivs, endet aber auf **-ē**: *celerrimē* (nicht *celerrime* ist richtig, aber *celerrimē* mit langem ē).
Die Formen *optimē, pessimē, maximē, minimē, plūrimē* sind **unregelmäßig**.
:::

## Präpositionen: der Anker im Satz

Präpositionen sind unveränderlich, stehen **vor** dem Nomen und bestimmen dessen **Kasus**:

### Mit Akkusativ: Richtung, Ziel, Bewegung

| Präposition | Bedeutung | Beispiel |
|---|---|---|
| **ad** | zu, nach, bei | *ad urbem venit* — er kam zur Stadt |
| **in** | in (hinein) | *in urbem īvit* — er ging in die Stadt |
| **per** | durch, durch hindurch | *per silvam iter fēcit* — er zog durch den Wald |
| **propter** | wegen | *propter bellum* — wegen des Krieges |
| **contra** | gegen | *contra hostēs* — gegen die Feinde |
| **trans** | über (hinweg) | *trans fluvium* — über den Fluss |
| **post** | nach (zeitlich) | *post bellum* — nach dem Krieg |
| **ante** | vor (zeitlich) | *ante mortem* — vor dem Tod |

### Mit Ablativ: Ort, Ursache, Begleitung, Instrument

| Präposition | Bedeutung | Beispiel |
|---|---|---|
| **in** | in (befindlich) | *in urbe est* — er ist in der Stadt |
| **cum** | mit | *cum amīcō* — mit dem Freund |
| **sine** | ohne | *sine pēne* — ohne Strafe |
| **ā/ab** | von (von … weg) | *ā Rōmā profectus* — von Rom aufgebrochen |
| **dē** | von, über | *dē bellō loquitur* — er spricht über den Krieg |
| **ex/e** | aus | *ex agrō* — aus dem Feld |
| **prō** | vor (zeitlich), für | *pro patria* — für das Vaterland |
| **sub** | unter | *sub arbore* — unter dem Baum |

:::begriff Präposition
**Begriff:** Ein unveränderliches Wort, das vor einem Nomen steht und dessen **Kasus** festlegt.
**Herkunft:** lat. *praepositio* = „vorangestellte (Wortart)“ (*prae-* voraus + *positio* Platzierung).
**Wichtig:** Die Präposition bestimmt den Kasus — *in urbe* (Ablativ, wo?) vs. *in urbem* (Akkusativ, wohin?). Das ist im Deutschen ein Fall, den es nicht gibt: „in der Stadt" vs. „in die Stadt“ sind beide im Deutschen Akkusativ.
**Verwandte Begriffe:** *Kasus*, *Ablativ*, *Akkusativ*, *Präpositionale*.
:::

:::merksatz Die 20 wichtigsten Präpositionen mit Fall
**Akkusativ:** ad, in, per, propter, contra, trans, post, ante, subt (ohne ad)
**Ablativ:** in, cum, sine, ā/ab, dē, ex, prō, sub, apud (Person/Ort)
**Beide:** cum (mit Personen: Akkusativ), in + Akkusativ/Ablativ, sub + Akkusativ/Ablativ.
:::

## Konjunktionen: die Verbindungselemente

### Satzverbindende Konjunktionen

| Konjunktion | Bedeutung | Beispiel |
|---|---|---|
| **et** | und | *puella et puer* |
| **aut** | oder | *aut ... aut* — entweder … oder |
| **sed** | aber (nach einem Komma!) | *sed nōn dixit* |
| **at** | aber (stärker) | *at ille …* |
| **tamen** | dennoch | |
| **autem** | jedoch (nach dem ersten Satzglied) | *Rōmānī autem fortēs erant* |
| **enim** | denn | *…, enim …* |
| **nam** | nämlich | |
| **igitur** | also, daher | |
| **nōn sōlum … sed etiam** | nicht nur … sondern auch | |
| **neque** | und nicht | |

### Nebensatz einleitende Konjunktionen

| Konjunktion | Bedeutung | Erwarteter Modus |
|---|---|---|
| **quod** | weil, dass | Indikativ |
| **quoniam** | weil | Indikativ |
| **cum** | als, weil (kausal) | Indikativ |
| **quamquam** | obwohl | Indikativ |
| **dum** | während, solange | Indikativ |
| **postquam** | nachdem | Indikativ |
| **antequam/priusquam** | bevor | Indikativ |
| **ut** | dass, damit | Konjunktiv |
| **nē** | dass nicht | Konjunktiv |
| **ne** (verbunden) | ob (Frage) | Konjunktiv |

:::begriff Konjunktion
**Begriff:** Ein unveränderliches Wort, das **Sätze oder Satzglieder** miteinander verbindet.
**Herkunft:** lat. *coniūnctiō* = „Verbindung“ (*con-* zusammen + *iungere* verbinden); lat. *coniungere*.
**Zwei Arten:** *satzverbindend* (et, sed, aut) und *nebensatz_einleitend* (quod, cum, ut).
**Verwandte Begriffe:** *Nebensatz*, *Hauptsatz*, *Konjunktiv*, *Subjunktiv*.
:::

:::begriff Ordnungszahl (numerāle ōrdinārium)
**Begriff:** Die Zahl, die eine **Stelle in einer Reihe** angibt: der dritte, der zehnte.
**Wichtig:** Ordnungszahlen werden wie Adjektive der 1./2. Deklination dekliniert und im Ablativ wie Adverbien gebraucht (*prīmō* = „zuerst").
**Verwandte Begriffe:** *Kardinalzahl*, *Adjektiv*, *Numerale*.
:::
