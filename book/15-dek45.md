:::ziel Lernziele
Nach diesem Kapitel kannst du:
- die 4. und 5. Deklination sicher bilden,
- das Genus dieser Nomen bestimmen,
- die Sonderformen (*domus*, *genūs*) einordnen,
- erkennen, dass diese Deklinationen selten sind — und sie deshalb sicher zu beherrschen.
:::

:::wortschatz
**manus, manūs** *f.* — Hand · **gradus, gradūs** *m.* — Schritt, Stand ·
**cornū, cornūs** *n.* — Horn · **conflictus, -ūs** *m.* — Zusammenstoß, Krieg ·
**exercitus, -ūs** *m.* — Heer · **usus, -ūs** *m.* — Gebrauch ·
**rēs, reī** *f.* — Sache, Angelegenheit, Staat · **speciēs, speciēī** *f.* — Gestalt, Art ·
**familia, -ae** *f.* — Familie · **faciēs, faciēī** *f.* — Gestalt, Gesicht
:::

## Die 4. Deklination: die -us-Gruppe

Nomen auf **-us** (nach einem Konsanten) oder auf **-ū** (Neutrum). Alle haben im Genitiv Singular **-ūs**.

| | m. (*gradus*) | f. (*manus*) | n. (*cornū*) |
|---|---|---|---|
| Nom. Sg. | gradus | manus | cornū |
| Gen. Sg. | gradūs | manūs | cornūs |
| Dat. Sg. | gradū | manuī | cornū |
| Akk. Sg. | gradum | manum | cornū |
| Abl. Sg. | gradū | manū | cornū |
| Nom. Pl. | gradūs | manūs | cornua |
| Gen. Pl. | graduum | manuum | cornuum |
| Dat. Pl. | gradibus | manibus | cornibus |
| Akk. Pl. | gradūs | manūs | cornua |

:::merksatz Die Endungen der 4. Deklination
**Singular:** -us | -ūs | -ū | -um | -ū
**Plural:** -ūs | -uum | -ibus | -ūs
Der Genitiv Plural endet auf **-uum** (nicht -ōrum!) — das ist das Erkennungsmerkmal.
:::

## Die 5. Deklination: die -ē-Gruppe

Nomen auf **-ēs** — und **alle** sind feminin. Der Genitiv Singular endet auf **-ēī**.

| | rēs, reī *f.* (Sache) | speciēs, speciēī *f.* (Art) |
|---|---|---|
| Nom. Sg. | rēs | speciēs |
| Gen. Sg. | reī | speciēī |
| Dat. Sg. | reī | speciēī |
| Akk. Sg. | rem | speciēm |
| Abl. Sg. | rē | speciē |
| Nom. Pl. | rēs | speciēs |
| Gen. Pl. | rērum | speciērum |
| Dat. Pl. | rēbus | speciēbus |
| Akk. Pl. | rēs | speciēs |

:::warn Das Ende vom Ende
Die 5. Deklination hat nur **zehn** Nomen im ganzen Latein — *rēs* (Sache/Staat), *speciēs* (Art/Artus), *faciēs* (Gestalt), *series* (Reihe), *quies*? (nein: *quiēs, quiētis* ist 3. Deklination!), *abies* (3.), *pēs* (3.).
Merke dir vor allem **rēs**: *rēs pūblica* = „der Staat" (wörtlich „die öffentliche Sache") — der Ausdruck, den jede lateinische Schulaufgabe kennt.
:::

## Die Sonderformen, die man kennen muss

| Nomen | Erklärung |
|---|---|
| **domus, -ūs** *f.* | „Haus" — **feminin**, 4. Deklination; hat zusätzlich *domī* (Locativ: „zu Hause") und *domum* (Akk.: „nach Hause") und *domō* (Abl.: „aus dem Haus") |
| **manus, -ūs** *f.* | „Hand" — feminin trotz -us |
| **genūs, genūs** *n.* | „Geschlecht, Art" — **Neutrum**, 4. Deklination, Gen. Sg. *genūs* |
| **rēs, reī** *f.* | „Sache" — 5. Deklination, wichtigstes Nomen der Gruppe |
| **cornū, cornūs** *n.* | „Horn" — Neutrum, Akkusativ wie Nominativ (*cornū*) |
| **pēs, pedis** *m.* | „Fuß" — **3. Deklination** mit Stammwechsel (*ped-*) |
| **nox, noctis** *f.* | „Nacht" — 3. Deklination, unregelmäßiger Plural *noctēs* |

:::begriff 4. und 5. Deklination — was zählt
**4. Deklination:** *manus, gradus, cornu, genūs, domus, exercitus, conflictus, situs, eventus, processus, habitus, adspectus*.
**5. Deklination:** *rēs, speciēs, faciēs, series, putō? (nein)*, *abies? (nein)*, *pēs? (nein)*, *quiēs? (nein)*, *series*, *species*, *rēs*, *quies? (nein)*.
**Lernaufwand:** Minimal. Wenn du das Genitiv-Ende kennst (-ūs bzw. -ēī), kannst du alles bilden.
:::

## Übungen

:::uebung
**A. Deklination bestimmen.** Zu welcher Deklination gehören: *exercitus, rēs, manus, speciēs, cornū, domus*?

**B. Formen bilden.**
1. *gradus* — Gen. Sg., Dat. Pl., Akk. Pl.
2. *rēs* — Akk. Sg., Gen. Pl., Nom. Pl.
3. *manus* — alle Singularformen

**C. Übersetzen.**
4. *Rēs pūblica est res pūblicae.*
5. *Exercitus magnus in castrīs erat.*
6. *Manus eius in tabulā scriptum habet?* → korrigiere!

**D. Verstehen.** Was bedeutet *domus* in: *domī sum, domō exeō, domum redeō, domī laudantur*?
:::

:::loesung
**A.**
*exercitus* → 4. Deklination · *rēs* → 5. Deklination · *manus* → 4. Deklination (feminin) · *speciēs* → 5. Deklination · *cornū* → 4. Deklination (Neutrum) · *domus* → 4. Deklination (feminin).

**B.**
1. *gradūs, gradibus, gradūs* 2. *rem, rērum, rēs* 3. *manus, manūs, manuī, manum, manū*

**C.**
4. „Der Staat ist die Sache des Volkes." (bzw. „Das Gemeinwesen ist die öffentliche Sache.")
5. „Das große Heer war im Lager."
6. Korrekt: *Manus eius in tabulā scriptum habet.* — *manus* ist 4. Deklination (Akk. Sg. *manum*), nicht *manus* (Nom.). Also: *Manum eius in tabulā scriptum habet?* = „Trägt er seine Hand auf der Tafel?" Hmm, *habet* mit Akkusativ + Infinitiv; *manum habet scriptum* = „er hat die Hand beschrieben". Besser: *Manus eius in tabulā scrīpta est.* = „Seine Hand ist auf der Tafel beschrieben."

**D.**
*domī* = „zu Hause" (Locativ) · *domō* = „aus dem Haus" (Abl. der Herkunft) · *domum* = „nach Hause" (Akk. der Richtung) · *domī* (2. Vorkommen, mit *laudantur*) = „zu Hause werden sie gelobt" (Locativ).
:::
