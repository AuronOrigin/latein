## Warum Wortbildung das wichtigste Werkzeug ist

Eine Sprache ist eine **Wortfamilie**. Wer die Wurzel kennt, versteht eine ganze Familie auf einmal — und erspart sich das Vokabellernen:

```
  agri-  (Feld)          + -cola  (Bauer)     → agrīcola     der Bauer
  agri-  (Feld)          + -cultūra (Pflege)   → agrīcultūra die Landwirtschaft
  fortis (tapfer)        + -itūdō (Art)       → fortitūdō    die Tapferkeit
  fortis (tapfer)        + -ānus  (Art)       → fortūnātus  der Glückliche
  magnus (groß)          + -itūdō             → magnitūdō    die Größe
  vīvus  (lebendig)      + -itālis             → vītālis      lebenswichtig
```

Das ist der Grund, warum man Latein-Vokabeln nicht stumpf auswendig lernt, sondern **über Wurzeln**: *Hier ist etwas unklar, aber die Wurzel kenne ich*.

## Die Präfixe

Präfixe stehen **vor** dem Wort und verändern dessen Bedeutung (oft im Sinne von „weg", „hinein", „um ... herum", „entgegen").

| Präfix | Bedeutung | Beispiel | Übersetzung |
|---|---|---|---|
| **a-/ab-** | von, weg | *abīre* | weggehen |
| **ad-** | zu, auf | *advenīre* | ankommen |
| **circum-** | um … herum | *circumīre* | umhergehen |
| **con-/com-** | mit, zusammen | *cōnsulere* | beraten |
| **dē-** | herab, von | *dēscendere* | hinabsteigen |
| **ex-** | aus | *exīre* | hinausgehen |
| **in-** | hinein | *intrāre* | eintreten |
| **per-** | durch | *perīre* | zugrunde gehen |
| **prō-** | vor, für | *prōgredī* | vorrücken |
| **re-** | zurück, wieder | *redīre* | zurückkehren |
| **sub-** | unter | *subīre* | hinuntergehen |
| **super-** | über | *superāre* | übertreffen |
| **trans-** | über, hinüber | *trānsīre* | hinübergehen |
| **contra-** | gegen | *contrādīcere* | widersprechen |

:::begriff Präfix
**Begriff:** Ein **unabtrennbarer** Vorspann, der die Bedeutung des Wortstammes verändert.
**Herkunft:** lat. *prae-* (vor) + *fīxus* (befestigt) — das „Vorangefügte“.
**Wichtig:** Präfixe sind im Latein **grammatisch unselbständig**: *ad-*, *in-*, *ex-* sind keine Wörter, sondern Teile. Man kann sie deshalb **nicht** mit einem Nomen verbinden (*ad puellam* gibt es nicht — das wäre *ad puellam* als „zu dem Mädchen" mit eigener Präposition!).
**Verwandte Begriffe:** *Suffix*, *Kompositum*, *Stamm*, *Wortfamilie*.
:::

:::warn Präfix oder Präposition?
Das ist eine häufige Fehlerquelle. **Präfixe** hängen **am Wort** (mit **keinem** Zwischenraum): *advenīre*. **Präpositionen** stehen **vor** dem Nomen (mit **Zwischenraum**): *ad puellam*. Im Deutschen sieht beides gleich aus („ankommen" / „zu ihr"), im Latein nicht.
**Beweis-Test:** Ist das erste Element ein Nomen, das für sich stehen kann? *ad* ist keine Präposition ohne Nomen — es ist ein Vorspann. *cum* dagegen ist eine echte Präposition.
:::

## Die wichtigsten Suffixe

### Nomen

| Suffix | Bedeutung | Beispiele |
|---|---|---|
| **-ātiō(n)** | Handlung, Zustand | *orātiō* (Rede), *nāvigātiō* (Seefahrt) |
| **-tūdō** | Größe, Zustand | *fortitūdō* (Tapferkeit), *multitūdō* (Menge) |
| **-mentum** | Mittel, Ergebnis | *ālimentum* (Nahrung), *ornāmentum* (Schmuck) |
| **-tiō(n)** | Handlung | *mōtiō* (Bewegung) |
| **-ōsus, -a, -um** | reich an … | *ferōx*? (nein), *famosus* (berühmt), *periculōsus* (gefährlich) |
| **-ālis, -e** | zu … gehörig | *nātūrālis* (natürlich), *mūlitāris* (militärisch) |
| **-ārius, -a, -um** | betreffend | *militārius* (Soldat), *vītārius* (Gliedmann) |
| **-ensis, -e** | aus … stammend | *Rōmānēnsis*? (*Rōmānus*), *Athēnēnsis* (athenisch) |
| **-īcus, -a, -um** | nach … benannt | *Cōmīcius* (komisch), *Pūblīcius* |
| **-ānus, -a, -um** | nach Art von | *fortūnānus* (glücklich), *Rōmānus* (römisch) |

### Verben

| Endung | Konjugation | Beispiele |
|---|---|---|
| **-āre** | 1. Konjugation | *amāre, laudāre* |
| **-ēre** | 2. Konjugation | *monēre, vidēre* |
| **-ere** | 3. Konjugation | *legere, dūcere* |
| **-īre** | 4. Konjugation | *audīre, venīre* |

:::begriff Suffix
**Begriff:** Ein **unabtrennbarer** Anhang am **Ende** eines Wortstammes, der die Wortart oder die Bedeutung festlegt.
**Herkunft:** lat. *suffīxus* = „das Angeheftete“ (*sub-* unter + *fīxus*).
**Nützlichste Regel:** Endet ein Wort auf **-āre, -ēre, -ere, -īre**, ist es ein **Verb** — und die Endung verrät die Konjugation. Endet es auf **-tiō, -tūdō, -mentum, -nis**, ist es ein **Nomen**.
**Verwandte Begriffe:** *Präfix*, *Stamm*, *Konjugation*, *Wortfamilie*.
:::

## Komposita: zwei Nomen, ein Wort

| Kompositum | Bestandteile | Bedeutung |
|---|---|---|
| **agrīcola** | *ager* (Feld) + *colere* (bauen) | der Bauer |
| **prīncipium** | *prīnceps* (Fürst) + *-ium* | der Anfang, die Grundlage |
| **magnanimus** | *magnus* (groß) + *animus* (Mut) | großherzig |
| **paenitentia** | *paenitēre* (bereuen) + *-ntia* | die Reue |
| **sempervivum** | *semper* (immer) + *vīvere* (leben) | das Immergrün |

:::begriff Kompositum
**Begriff:** Ein Wort, das aus **zwei oder mehr** selbständigen Wörtern zusammengesetzt ist.
**Herkunft:** lat. *compositum* = „Zusammengestelltes“ (*com-* zusammen + *ponere* legen).
**Wichtig:** Im Latein steht das **Bestimmungswort zuerst** (im Deutschen meist das letzte): *magnanimus* = „mit großem Mut“, nicht „großmutig“ in der deutschen Reihenfolge.
**Verwandte Begriffe:** *Präfix*, *Suffix*, *Wortfamilie*.
:::

## Die Übung, die am meisten bringt: Wurzeln raten

Wenn du ein unbekanntes Wort siehst, geh so vor:

**Schritt 1:** Zerlege es in Wurzel + Endung.
**Schritt 2:** Suche die Wurzel in deinem bekannten Vokabelbestand.
**Schritt 3:** Errate die Bedeutung — ungefähr reicht.
**Schritt 4:** Prüfe im Wörterbuch.

> *bēllōsus* → *bellum* (Krieg) + *-ōsus* (voll von …) → „kriegsüchtig, kriegslustig"
> *cōnscriptus* → *con- + scrībere* (schreiben) → „zusammengeschrieben, eingerückt" → „Soldat (der eingetragen wurde)"
> *trānsportōsus* → *trans- + portus* (Hafen) → „über den Hafen hinweg" → „schnell, flink"

## Übungen

:::uebung
**A. Präfixe.** Erkläre die Bedeutung und bilde die Form:
1. *adferō* 2. *dēferō* 3. *exferō* 4. *circumferō* 5. *trānsferō*

**B. Wortfamilien.** Leite die Wörter einer Wurzel zu:
6. *fortis* 7. *vīvus* 8. *magnus*

**C. Bedeutung erraten.** Errate die Bedeutung ohne Wörterbuch:
9. *bēllōsus* 10. *nāvigātiō* 11. *magnanimus* 12. *vītālis* 13. *periculōsus*

**D. Wortart erkennen.** Nenne die Wortart und begründe:
14. *cantō, cantāre* 15. *fortitūdō* 16. *agricultura* 17. *militāris* 18. *rēgīna*
:::
